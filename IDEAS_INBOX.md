# 📬 Boîte aux idées AdeleM — miroir local

⚠️ **La boîte principale n'est plus ce fichier.**

La source de vérité pour les nouvelles idées d'Adèle est le Google Doc partagé :

**AdeleM — Boîte aux idées**  
https://docs.google.com/document/d/1UTr09YCduog4OAU-dDFu3PGSWuql3Fs2i0i3iOqTCCU/edit

Ce fichier reste dans le dépôt comme **historique / secours local**. Il ne faut jamais supposer qu'il contient les idées les plus récentes sans avoir consulté le document partagé.

## Règle pour l'IA qui construit le site

Avant toute session significative :

1. ouvrir le Google Doc partagé ;
2. lire les idées `À étudier` ;
3. les confronter à `docs/doctrine-adelem.md`, `docs/decisions.md` et à l'état réel du site ;
4. ne jamais considérer une idée comme validée simplement parce qu'elle a été déposée ;
5. si une idée devient une décision structurante, l'inscrire dans `docs/decisions.md`.

Si l'accès au Google Doc est impossible, l'IA doit le signaler explicitement au lieu d'ignorer la boîte.

# Architecture V5

Structure cible:
- `/` — Accueil
- `/oeuvres/` — Galerie des œuvres
- `/oeuvres/oeuvre-exemple/` — gabarit de fiche œuvre
- `/cadres-anciens/` — Cadres anciens
- `/sculptures/` — Sculptures
- `/sur-mesure/` — Sur mesure
- `/collections-privees/` — Collections privées
- `/atelier/` — Atelier / à propos
- `/contact/` — Contact

Principe:
- la homepage est la priorité artistique actuelle ;
- les autres routes existent immédiatement pour stabiliser la navigation et l’architecture ;
- leur design final sera développé une par une après validation de la homepage ;
- GitHub conserve le code ; les binaires lourds validés restent hors GitHub via Drive/CDN.

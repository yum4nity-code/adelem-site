# AdeleM V5 — Direction artistique

Cette V5 repart du fond stratégique validé, mais rejette l’habillage trop générique de la version précédente.

## Règle absolue

**Chaque écran doit pouvoir être screenshoté et avoir de la gueule tout seul.**

Le site doit donner la sensation d’entrer dans l’univers d’une artiste-artisane, pas dans un template de décoration premium.

## Ce que la V5 doit corriger

- impossible de remplacer AdeleM par une autre marque sans que le site perde son sens
- plus de matière : relief, macro, geste, détails, ombre, respiration
- le logo doit devenir un élément de composition, pas seulement un identifiant dans le header
- typographie moins “site design”, plus éditoriale et plus personnelle
- mobile composé spécifiquement, pas simplement réduit
- rythme irrégulier : grands silences, ruptures, images plein cadre, asymétries
- la galerie doit ressembler à une galerie
- Collections privées, Sculptures et Sur mesure doivent chacune avoir une atmosphère propre
- le visiteur doit ressentir AdeleM avant de comprendre qu’il peut acheter

## Mécanique commerciale

Accueil :
**désir → différence → matière → geste → confiance → projection**

Pages œuvres :
**clarté → prix → dimensions → disponibilité → livraison → acquisition**

Donc :
- aucun prix sur la homepage
- pas de fausse urgence
- pas de promotions
- prix visibles dès qu’on entre dans la galerie / une œuvre
- contact humain possible pour les pièces importantes
- œuvres vendues conservées sous **Collections privées**

## Ton

- peu de texte
- phrases courtes
- précision
- sensibilité sans emphase
- jamais de jargon artistique creux
- aucun point final dans les titres

# AdeleM — pack logo officiel

Les fichiers de ce dossier sont destinés au site, aux réseaux, aux cartes de visite et à l’impression.

## Vectoriel — à privilégier
- `vector/adelem-wordmark-copper.svg` — signature principale, extraite de l’original fourni.
- `vector/adelem-wordmark-charcoal.svg` — signature sombre sur fond clair.
- `vector/adelem-wordmark-white.svg` — signature blanche sur fond sombre.
- `vector/adelem-badge-dark.svg` — logo circulaire propre inspiré de la composition originale : fond très sombre, cercle cuivre, signature fidèle et évocation botanique.
- `vector/adelem-badge-transparent.svg` — même badge sans fond.

## PNG HD transparent
Le dossier `raster/` contient les versions PNG haute définition, dont les trois signatures avec transparence et le badge circulaire transparent.

## Web
Le dossier `web/` contient des WebP optimisés en 512 et 1024 px.

## Icônes
Le dossier `favicon/` contient les tailles navigateur / mobile.

## Couleurs
- Cuivre / rose : `#D58A6F`
- Charbon : `#171714`
- Fond badge : `#0C0F0C`
- Blanc : `#FFFFFF`

## Règles
Ne pas étirer, incliner ni modifier les proportions.  
Pour l’impression, utiliser le SVG. Pour le web, utiliser SVG ou WebP. Pour superposer le logo sur une image, utiliser un SVG ou PNG transparent.

La signature a été vectorisée directement à partir de l’image originale fournie ; ce n’est pas une réinterprétation typographique.

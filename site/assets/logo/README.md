# Identité visuelle AdeleM — logos

Ce dossier contient les fichiers officiels dérivés du logo original fourni par AdeleM.

## Référence

- `master/adelem-original-master.png` : fichier source original, conservé intact.
- `raster/adelem-logo-original-round-transparent.png` : logo circulaire fidèle à l’original, avec l’extérieur du cercle transparent.

## Signature / wordmark

La signature `Adelem` est extraite directement du logo original puis vectorisée ; elle n’est pas redessinée.

- `vector/adelem-wordmark-copper.svg` : version principale cuivre / rose.
- `vector/adelem-wordmark-charcoal.svg` : version sombre sur fond clair.
- `vector/adelem-wordmark-white.svg` : version blanche sur fond sombre.
- `raster/*-transparent.png` : équivalents PNG HD à fond transparent.

## Web

- `web/adelem-logo-original-round-512.webp` : logo rond léger pour le web.
- `web/adelem-logo-original-round-1024.webp` : version web haute définition.
- `favicon/` : icônes navigateur, raccourcis et mobile.

## Couleurs

- Cuivre / rose signature : `#D58A6F`
- Charbon : `#171714`
- Blanc : `#FFFFFF`

## Usage recommandé

- Fond sombre : signature cuivre ou blanche.
- Fond clair : signature charbon ou cuivre.
- Avatar / sceau / favicon : logo circulaire original.
- Carte de visite / impression : SVG en priorité ; PNG transparent HD en second choix.

Ne pas étirer, incliner ou modifier les proportions. Le fichier `master` reste la référence visuelle.
